# DLF-Scripts
This repository contains some complementary scripts, information and tutorials for using the Dual Latent Fusion Codec (DLF Codec).

The official page for the project can be found [here](https://dlfcodec.github.io/).

Their amazing paper can be read through this [.pdf link](https://arxiv.org/pdf/2503.01428) and through It's [arXiv page](https://arxiv.org/abs/2503.01428).

The main code is available at [It's Github page](https://github.com/dlfcodec/Dual-generative-Latent-Fusion).

## For my simple contributions

Here you can find the scripts, information, and tutorials that I have added to complement the official DLF Codec repository.

The `How to DLF.md` file includes step-by-step guides on how to configure the whole environment, run the scripts, and utilize the DLF Codec effectively.

Inside the `Scripts` directory, you will find some Python scripts that I have created to facilitate the use of the DLF Codec, such as the compressor and the decompressor script.

Obviously, these scripts are meant to complement the official DLF Codec repository and are not intended to replace any of the official tools or models. And as you can see, my abilities are quite limited, so feel free to provide feedback, suggestions for improvement and contributions. Thank you for your support!
